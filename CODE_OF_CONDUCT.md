# Code of conduct

We want these projects to be a place where people can do good work together.

- Be respectful. Disagree with ideas, not people.
- No harassment, insults, discrimination or unwelcome personal attention.
- Do not publish other people's private information.
- Keep discussion on topic and in good faith.

Maintainers may edit or remove comments, close issues and block people who break these rules. Report a problem by email to hello@haorgrix.com. Reports are handled in confidence.

This code applies in all project spaces: issues, pull requests, discussions and any place where you represent the project.
